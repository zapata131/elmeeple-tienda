# Conversational Copywriting Standards Playbook

This document defines the copywriting standards and conversational guidelines required to align **MeeplePrecios** with the Google Developer Documentation Style Guide. All UI copy, labels, placeholders, errors, and success notifications must follow these rules.

---

## 1. Core Voice and Tone Guidelines

We communicate with our users in a **warm, professional, direct, and helpful** voice.

### 1.1 Active Voice and Second Person
*   Address the user in the second person ("you" / "tú/tus/usted") to establish a direct, conversational connection.
*   Use active voice instead of passive voice to make actions clear and immediate.
    *   **Before (Mechanical)**: *"Debes registrarte para guardar alertas."*
    *   **After (Active/Helpful)**: *"Inicia sesión para guardar tus alertas de precio."*

### 1.2 Humanized Technical Language
*   Translate backend processes into clear, human benefits.
    *   **Before**: *"Buscando en bgg_games_cache con query EAN/UPC..."*
    *   **After**: *"Comprobando disponibilidad y mejores ofertas en tiempo real"*

---

## 2. Casing Standards: Sentence Case

To maintain a clean, contemporary design aesthetic, all user-facing copy must use **sentence case**. Capitalize only the first word and proper nouns (e.g. brand names like BGG, BoardGameGeek, MeeplePrecios, Zygomatic).

### Examples of Correct Sentence Case
*   **Page Headings**: `Comparador de precios`, `Ludoteca y seguimiento`, `Reseñas de embalaje`
*   **Form Labels**: `País de destino`, `Moneda mostrada`, `Umbral de envío gratis`
*   **Button Actions**: `Avísame cuando haya stock`, `Añadir +`, `Explorar catálogo`

---

## 3. Human-Centric Error Casing and Alerts

*   **Rule 1: No Exclamation Marks in Errors**: Keep error messages calm.
*   **Rule 2: Offer a Clear Solution**: Explain how the user can resolve the issue.
*   **Rule 3: Avoid Decorative Ellipses**: Use clean text without unnecessary ellipses.
